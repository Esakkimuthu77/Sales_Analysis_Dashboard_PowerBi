# Sales_Analysis_Dashboard_PowerBi


## Project Overview
This project focuses on cleaning and analyzing retail store sales data using Python and Pandas, preparing the data in Excel, and creating an interactive Retail Sales Performance Dashboard.

The dashboard helps explore sales revenue, transactions, quantities sold, customers, product categories, payment methods, and store locations.

## Project Objectives
- Inspect and understand a raw retail sales dataset.
- Identify missing values and examine data quality.
- Convert transaction dates into a proper date format.
- Handle missing unit prices where sufficient information is available.
- Perform exploratory data analysis using Pandas.
- Prepare a cleaned dataset for dashboard reporting.
- Visualize retail sales performance using a dashboard.

## Tools and Technologies
- **Python** – Data cleaning and analysis
- **Pandas** – Data manipulation and missing-value analysis
- **NumPy** – Numerical operations
- **Jupyter Notebook** – Python development environment
- **Microsoft Excel** – Cleaned dataset storage
- **Microsoft Power BI** – Interactive dashboard visualization

## Dataset Description
The cleaned dataset contains **12,575 rows and 10 columns**.

| Column | Description |
|---|---|
| Transaction ID | Unique transaction identifier |
| Customer ID | Customer identifier |
| Category | Product category |
| Price Per Unit | Price of one unit |
| Quantity | Number of units purchased |
| Total Spent | Total amount spent on a transaction |
| Payment Method | Payment method used |
| Location | Online or in-store transaction |
| Transaction Date | Date of the transaction |
| Discount Applied | Discount indicator |

The transaction dates range from January 2022 to January 2025.

## Data Cleaning and Analysis
The following tasks were performed in the Python notebook:

1. Imported the raw CSV dataset using Pandas.
2. Examined dataset structure, data types, descriptive statistics, and missing values.
3. Removed the `Item` column because it was not required for the analysis.
4. Converted `Transaction Date` into a datetime data type.
5. Identified missing values in `Price Per Unit`, `Quantity`, and `Total Spent`.
6. Calculated missing unit prices using `Total Spent / Quantity` when the required values were available.
7. Examined missing quantities and total-spent values using customer, category, and price information.
8. Created a temporary calculated-total column to compare `Price Per Unit × Quantity` with `Total Spent`.
9. Checked duplicate rows and duplicate transaction IDs.
10. Explored product categories, payment methods, locations, transaction dates, and numerical summaries.
11. Exported the prepared dataset to an Excel file.

**Data quality note:** The exported dataset still contains missing values in `Quantity` (604 rows), `Total Spent` (604 rows), and `Discount Applied` (4,199 rows). These values should be reviewed or handled before treating the dataset as completely cleaned.

## Power BI Dashboard

The Retail Sales Performance Dashboard includes:

### Key Performance Indicators (KPIs)
- Total Revenue
- Total Transactions
- Total Quantity
- Total Customers
- Average Order Value

### Visualizations
- **Monthly Revenue Trend:** Tracks revenue across months.
- **Top 10 Customers:** Compares the highest-spending customers.
- **Revenue by Category:** Shows revenue generated by each product category.
- **Transactions by Payment Method:** Compares Cash, Credit Card, and Digital Wallet transactions.
- **Transactions by Location:** Compares Online and In-store transactions.
- **Year Slicer:** Filters the dashboard by year.
